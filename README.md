# บันทึกกระแสเงินสด

แอปเว็บสำหรับบันทึกรายรับ-รายจ่ายส่วนตัว ทำงานแบบหน้าเดียว (SPA) เก็บข้อมูลไว้ในเครื่อง (`localStorage`) ไม่ต้องมีเซิร์ฟเวอร์

## โครงสร้างไฟล์

```
project/
├── index.html      โครงหน้าเว็บและทุกหน้าของแอป
├── css/
│   └── style.css   ธีมสีและการจัดวาง
├── js/
│   └── script.js   โลจิกทั้งหมดของแอป
└── README.md
```

## ฟีเจอร์หลัก

- **หน้าหลัก**: บันทึกรายรับ-รายจ่าย (วันที่ ประเภท หมวดหมู่ จำนวนเงิน หมายเหตุ) ดูรายการย้อนหลังพร้อมกรองตามเดือน
- **หน้าเงินยืม-คืน**: บันทึกรายการยืม/ให้ยืม พร้อมสถานะ (ยืมอยู่/คืนแล้ว/คืนบางส่วน)
- **หน้าหมวดหมู่**: เพิ่ม/แก้ไข/ลบ หมวดหมู่รายรับและรายจ่ายแยกกัน มีหมวดหมู่เริ่มต้นให้พร้อมใช้งาน
- **หน้าหนี้สิน/บัตรเครดิต**: บันทึกวงเงิน ยอดคงเหลือ ดอกเบี้ย วันครบกำหนด ยอดขั้นต่ำ พร้อมแถบแสดงสัดส่วนการใช้วงเงิน
- **หน้ารายการประจำ**: ตั้งรายการที่ต้องจ่าย/รับทุกเดือน ระบบจะ**เพิ่มเป็นรายการจริงในหน้าหลักให้อัตโนมัติ**ทุกครั้งที่เปิดแอป เมื่อถึงวันที่กำหนดของเดือนนั้น (ตรวจสอบย้อนหลังให้สูงสุด 36 เดือน กรณีไม่ได้เปิดแอปนาน)
- **หน้าแดชบอร์ด**: เลือกดูแบบทั้งหมดหรือรายเดือน มีการ์ดสรุปยอดรวม, กราฟวงกลมสัดส่วนรายจ่ายตามหมวดหมู่, กราฟแท่งเทียบรายรับ-รายจ่าย 6 เดือนล่าสุด, กราฟเส้นแนวโน้มเงินสะสม
- **หน้าตั้งค่า**: นำเข้า/ส่งออกข้อมูลเป็น `.json` หรือ `.xlsx` และล้างข้อมูลทั้งหมด

## ข้อควรทราบ

- ข้อมูลทั้งหมดเก็บอยู่ใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ๆ **ถ้าล้างแคช/ข้อมูลเว็บไซต์ หรือเปลี่ยนเบราว์เซอร์ ข้อมูลจะหายไป** ควรกด Export เป็น `.json` เก็บสำรองไว้เป็นประจำ
- ฟีเจอร์ Export/Import `.xlsx` และกราฟในหน้าแดชบอร์ด **ต้องมีอินเทอร์เน็ต** เพราะโหลดไลบรารี SheetJS และ Chart.js จาก CDN (`cdnjs.cloudflare.com`) ส่วนการบันทึกรายการปกติใช้งานแบบออฟไลน์ได้
- การนำเข้าไฟล์ (Import) จะ**แทนที่ข้อมูลเดิมทั้งหมด** ควร Export สำรองไว้ก่อนทุกครั้ง

## วิธีใช้งานบนมือถือ (Android)

**เปิดดูผลลัพธ์ด้วย Acode:**
1. เปิดโฟลเดอร์โปรเจกต์นี้ใน Acode
2. เปิดไฟล์ `index.html` แล้วกดปุ่ม "Run" ของ Acode (ไอคอนรูปเล่นที่มุมขวาบน) เพื่อดูตัวอย่างในเบราว์เซอร์

**หรือรันผ่าน Termux (แนะนำถ้าต้องการทดสอบ Import/Export ให้ครบ):**
```bash
cd path/to/project
python -m http.server 8080
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

**อัปโหลดขึ้น GitHub ด้วยแอป GitHub:**
1. สร้าง repository ใหม่ (หรือใช้ของเดิม)
2. เพิ่มไฟล์ `index.html`, `css/style.css`, `js/script.js` ตามโครงสร้างด้านบน
3. ถ้าต้องการโฮสต์ฟรีให้เข้าถึงได้ทุกที่ ให้เปิดใช้ GitHub Pages ที่ตั้งค่า repository

## การปรับแต่งเพิ่มเติม

- เปลี่ยนโทนสี: แก้ค่าตัวแปรในส่วน `:root` ของ `css/style.css`
- เปลี่ยน/เพิ่มหมวดหมู่เริ่มต้น: แก้ค่าคงที่ `DEFAULT_CATEGORIES` ในบรรทัดต้น ๆ ของ `js/script.js` (มีผลเฉพาะตอนเปิดแอปครั้งแรกที่ยังไม่มีข้อมูลหมวดหมู่)
