# บันทึกกระแสเงินสด

แอปเว็บสำหรับบันทึกรายรับ-รายจ่ายส่วนตัว ทำงานแบบหน้าเดียว (SPA) เก็บข้อมูลบน **Cloud Firestore** (Firebase / Google Cloud) ผูกกับบัญชี Google ของคุณ ใช้งานออฟไลน์ได้และซิงก์ขึ้นคลาวด์เองเมื่อมีอินเทอร์เน็ต ไม่ต้องมีเซิร์ฟเวอร์ของตัวเอง

> ใช้งานครั้งแรกต้องตั้งค่า Firebase ก่อน ดูขั้นตอนที่ [docs/firebase-setup.md](docs/firebase-setup.md)

## โครงสร้างไฟล์

```
project/
├── index.html      โครงหน้าเว็บและทุกหน้าของแอป
├── css/
│   └── style.css   ธีมสีและการจัดวาง
├── js/
│   ├── script.js          โลจิกหน้าจอทั้งหมดของแอป
│   ├── store-boot.js      โหลด Firebase SDK และสร้างส่วนเก็บข้อมูล
│   ├── store.js           ส่วนเก็บข้อมูล (cache + ซิงก์กับ Firestore + ย้ายข้อมูลเก่า)
│   ├── store-core.js      ฟังก์ชันช่วยของส่วนเก็บข้อมูล (ทดสอบได้ด้วย Node)
│   └── firebase-config.js ค่าตั้งค่าโปรเจกต์ Firebase (ต้องแก้เอง)
├── sw.js           Service Worker เก็บไฟล์แอปไว้ใช้ตอนออฟไลน์
├── manifest.webmanifest  ข้อมูลแอปสำหรับติดตั้งบนหน้าจอโฮม (PWA)
├── icons/          ไอคอนแอป (สร้างด้วย scripts/make-icons.py)
├── firestore.rules กฎความปลอดภัย: แต่ละบัญชีเห็นเฉพาะข้อมูลตัวเอง
├── firebase.json   ตั้งค่า Firebase Emulator สำหรับทดสอบ
├── tests/          เทสต์ (npm test / npm run test:emu)
├── docs/firebase-setup.md  ขั้นตอนตั้งค่า Firebase
└── README.md
```

## ฟีเจอร์หลัก

- **หน้าหลัก**: บันทึกรายรับ-รายจ่าย (วันที่ ประเภท หมวดหมู่ จำนวนเงิน หมายเหตุ) ดูรายการย้อนหลังพร้อมกรองตามเดือน
- **หน้าเงินยืม-คืน**: บันทึกรายการยืม/ให้ยืม พร้อมสถานะ (ยืมอยู่/คืนแล้ว/คืนบางส่วน)
- **หน้าหมวดหมู่**: เพิ่ม/แก้ไข/ลบ หมวดหมู่รายรับและรายจ่ายแยกกัน มีหมวดหมู่เริ่มต้นให้พร้อมใช้งาน
- **หน้าหนี้สิน/บัตรเครดิต**: บันทึกวงเงิน ยอดคงเหลือ ดอกเบี้ย วันครบกำหนด ยอดขั้นต่ำ พร้อมแถบแสดงสัดส่วนการใช้วงเงิน
- **หน้ารายการประจำ**: ตั้งรายการที่ต้องจ่าย/รับทุกเดือน ระบบจะ**เพิ่มเป็นรายการจริงในหน้าหลักให้อัตโนมัติ**ทุกครั้งที่เปิดแอป เมื่อถึงวันที่กำหนดของเดือนนั้น (ตรวจสอบย้อนหลังให้สูงสุด 36 เดือน กรณีไม่ได้เปิดแอปนาน)
- **หน้าแดชบอร์ด**: เลือกดูแบบทั้งหมดหรือรายเดือน มีการ์ดสรุปยอดรวม, กราฟวงกลมสัดส่วนรายจ่ายตามหมวดหมู่, กราฟแท่งเทียบรายรับ-รายจ่าย 6 เดือนล่าสุด, กราฟเส้นแนวโน้มเงินสะสม
- **หน้าตั้งค่า**: บัญชีที่ล็อกอิน/ออกจากระบบ, นำเข้า/ส่งออกข้อมูลเป็น `.json` หรือ `.xlsx` และล้างข้อมูลทั้งหมด
- **ซิงก์ข้อมูล**: ไอคอนเมฆที่แถบบนบอกสถานะ ซิงก์แล้ว / รอส่งขึ้นคลาวด์ / ผิดพลาด

## ข้อควรทราบ

- ข้อมูลทั้งหมดเก็บบน **Cloud Firestore** ภายใต้บัญชี Google ที่ล็อกอิน ล้างแคชหรือเปลี่ยนเครื่องข้อมูลก็ไม่หาย แค่ล็อกอินบัญชีเดิม
- ล็อกอินครั้งเดียว แอปจะจำไว้ เปิดตอนออฟไลน์ก็ใช้ได้ (ต้องเคยเปิดตอนออนไลน์อย่างน้อย 1 ครั้ง) รายการที่บันทึกตอนออฟไลน์จะถูกส่งขึ้นคลาวด์เองเมื่อมีเน็ต
- ต้องเปิดผ่าน **HTTPS** (เช่น GitHub Pages) หรือ **`http://localhost`** เท่านั้น การเปิดไฟล์ `index.html` ตรง ๆ จะล็อกอินไม่ได้
- ล็อกอินครั้งแรก ข้อมูลเดิมที่เคยเก็บใน `localStorage` จะถูกย้ายขึ้นคลาวด์ให้อัตโนมัติ (สำเนาเดิมยังอยู่ในเครื่องจนกว่าจะกด "ล้างข้อมูลสำรองเก่าในเครื่อง" ในหน้าตั้งค่า)
- การนำเข้าไฟล์ (Import) และการล้างข้อมูล **มีผลกับทุกเครื่อง**ที่ล็อกอินบัญชีนี้ ควร Export สำรองไว้ก่อนทุกครั้ง
- กราฟและ Export/Import `.xlsx` ใช้ไลบรารีจาก CDN ซึ่งจะถูกเก็บไว้ในเครื่องหลังเปิดแอปออนไลน์ครั้งแรก

## วิธีใช้งานบนมือถือ (Android)

**ติดตั้งเป็นแอปบนหน้าจอโฮม (PWA):**
1. เปิด `https://saharatyokthuan.github.io/cash-manager/` ใน Chrome แล้วล็อกอิน
2. กดเมนู ⋮ → **ติดตั้งแอป** (หรือ **เพิ่มลงในหน้าจอหลัก**)
3. แอปจะมีไอคอนบนหน้าจอโฮม และเปิดเต็มจอโดยไม่มีแถบเบราว์เซอร์ ใช้ข้อมูลชุดเดียวกับที่ล็อกอินในเว็บ
   (iPhone: เปิดใน Safari → ปุ่มแชร์ → **เพิ่มไปยังหน้าจอโฮม**)


**รันผ่าน Termux (แนะนำ เพราะได้ `localhost` ที่ล็อกอิน Google ได้):**
```bash
cd path/to/project
python -m http.server 8080
```
แล้วเปิดเบราว์เซอร์ไปที่ `http://localhost:8080`

**อัปโหลดขึ้น GitHub ด้วยแอป GitHub:**
1. สร้าง repository ใหม่ (หรือใช้ของเดิม)
2. เพิ่มไฟล์ทั้งหมดตามโครงสร้างด้านบน
3. เปิดใช้ GitHub Pages ที่ตั้งค่า repository (รายละเอียดใน [docs/firebase-setup.md](docs/firebase-setup.md))

## การปรับแต่งเพิ่มเติม

- เปลี่ยนโทนสี: แก้ค่าตัวแปรในส่วน `:root` ของ `css/style.css`
- เปลี่ยน/เพิ่มหมวดหมู่เริ่มต้น: แก้ค่าคงที่ `DEFAULT_CATEGORIES` ในบรรทัดต้น ๆ ของ `js/script.js` (มีผลเฉพาะบัญชีที่ยังไม่มีข้อมูลหมวดหมู่บนคลาวด์)
